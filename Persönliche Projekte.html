Site web sur warhammer40k

Lien vers le code github

Site encyclopédique léger sur l'univers de warhammer 40k. Ce site présente des factions, personnages et planètes connues de cet univers et propose une boutique fictive. On peut s'y créer un profil de joueur, procéder à des achats dans la boutique et consulter les statistiques de cette dernière.

Le site est construit selon une architecture MVC avec une base de données mysql. Il est codé presque intégralement en php. Le fichier index.php va récupérer les méthodes $_GET, $_POST et les liens de la vue pour les envoyer en traitement aux contrôleurs. Le site est structuré avec un controleur par modèle et non un contrôleur par vue, ce qui signifie que certaines vues font appel à plusieurs contrôleurs. Il y a un modèle par table dans la base de donnée. Ces modèles récupèrent les données nécessaires aux contrôleurs qui les récupérent et les renvoient à la vue.

La base de données est composé d'une table factions, personnages, planètes, utilisateur, minifigs, joueur, et achat. Toutes les classes du site ne sont instanciées qu'une seule fois puis utilisées pendant l'utilisation du site et il n'y a pas de communication entre les contrôleurs.

Le site ne possède qu'un fichier css et un fichier js, tous deux plutôt optimisés.

Bot discord

Lien vers le code github

Un de mes premiers projets, réalisé en terminale codé intégralement en python. Ce bot discord est, comme son nom l'indique, un bot discord, qui peut être ajouté à n'importe quel serveur discord et modifié à tout moment si on a son TOKEN unique.

Pour le coder, j'ai fais appel à l'api de discord et ses extensions, ainsi qu'asyncio et diverses API pour la musique telles que youtube_dl, youtube_dl2, spotify, etc. Malheureusement toutes les bibliothèques faciles d'utilisation en python sont obsolètes aujourd'hui principalement pour des raisons de droits d'auteur donc la partie musicale du bot ne fonctionne pas.

Le bot a des fonctionnalités de modération automatique et manuelle, de chat avec les membres du serveur, de musique (en théorie), de roleplay (on peut se créer un personnage avec des attributs), et d'économie évolutive au cours des utilisations.

Il utilise une base de données composée de trois tables qui récupèrent les id des utilisateurs de discord et des serveurs afin de fonctionner en ligne sur plusieurs serveurs différents. Son code est organisé en POO pour accéder à ces bases de données et exécuter toutes les opérations qui ne sont pas relatives à discord. Pour ce qui est des commandes discord, celles-ci sont toutes implémentées dans le main, de même que sa connexion.

Jeu RP texte

Lien vers le code github

Ce jeu est mon premier projet en programmation. Il est codé intégralement en python sans utiliser d'API. Il ne possède pas d'interface utilisateur et n'est pas dynamique. C'est un script écrit qui est exécuté et des choix sont proposés à l'utilisateur tels les "livres dont vous êtes le héro", on pourra des fois faire des choix mais tout est codé à l'avance.

Le projet est très rudimentaire, il est POO tout de même avec une classe pour les joueurs, une pour les pnj, une pour les armes, une pour les armures, une pour les items, une pour les classes de personnage et une classe par classe spécifique qui hérite de la superclasse Classe.

Les objets des classes communiquent entre eux via des méthodes sans jamais appeler de getter et de setter afin de relier un personnage à son équipement par exemple, ou à sa position dans le monde.

Site web sur le cinéma

Lien vers le code github
Lien vers le site

Site web en html css avec un bout de javascript sur le cinéma globalement. Le site possède une page d'accueil qui fait une brève description du site, accompagnée d'un formulaire de newsletter, ainsi que d'une barre de navigation pour naviguer entre les pages. Il possède une page renseignant différents sites de critiques que l'on peut visiter directement via des liens, et un input dans lequel on peut rentrer le nom d'un film série, etc, qui va lier le résultat de cette barre de recherche aux liens des sites externes pour permettre d'aller directement rechercher sur tous les sites la série que l'on veut. Une page films du moment et une page série du moment sont également disponibles, qui possèdent une description des 5 séries et films les plus populaires du moment avec un lien redirigeant vers la page imdb de ce film/série. Le site a également un bouton de changement de thème pour passer du thème clair au sombre et inversement.

Dans le code il y a un fichier html par page et un fichier css en tout qui gère toutes les pages du site, le site est dynamique en partie mais il ne stocke rien, il n'y a donc pas de base de donnée, pas de principe d'utilisateur, lorsqu'on arrive dessus on peut l'utiliser. Le changement de thème et la barre de recherche sont gérées par le script en javascript.

Etant mon premier site web, les fonctionnalités sont limitées et le css est rudimentaire mais le tout est fonctionnel.

Installation Apache2

Télécharger le tuto

Installation d'apache2 à partir d'un tutoriel sur une VM debian linux neuve. Installation faite purement en lignes de commandes, installation d'apache puis configuration dans /etc/apache2 et utilisation des commandes propres à apache (systemctl restart apache2...) Apache 2 est un serveur HTTP (sûrement le plus populaire). Apache sert donc à communiquer avec un navigateur en utilisant le protocole HTTP(S) pour mettre en place ses propres sites web, les héberger et il est souvent utilisé avec un serveur LAMP (Linux Apache MySql/MariaDb Php) afin d'accéder à des bases de données.

Installation LAMP OCS-GLPI

Télécharger le tuto

Installation d'un serveur LAMP OCS-GLPI sur une VM debian linux possédant apache2. Installation en lignes de commandes suivi sur un tuto avec l'installation complémentaire de MariaDB, Php, OCS et GLPI car l'installation d'apache2 était déjà faite. LAMP ou Linux Apache MySql/MariaDb PHP est une pile logicielle qui permet de mettre en place un serveur web. Elle comporte un système d'exploitation, un serveur HTTP, un SGBD et un langage de programmation. Les 4 combinés permettront de communiquer avec le site web via le protocole HTTP(S), interpréter les requêtes et y répondre aux moyens d'un script, agissant sur le site en lui-même et sur la base de donnée dont les données peuvent être manipulées, supprimées et ajoutées. OCS GLPI quant à eux sont des logiciels permettant d'inventorier le matériel et les logiciels d'un parc informatique via un navigateur internet et proposent une intégration de logiciels et de systèmes de ticketing.

Installation windows serveur 2022 AD-DNS-DHCP

Télécharger le tuto

Windows serveur est un système d'exploitation de serveurs développé par microsoft qui permet de gérer le réseau en général, nécessaire pour les entreprises. On peut s'en servir pour optimiser nos performances, créer des groupes de travail et de partage, gestion des utilisateurs et de leur identité, renforcer la sécurisation des données... L'Active Directory est l'élément base de données qui met en lien les utilisateurs avec les ressources réseau dont ils ont besoin et leurs autorisations. Le serveur DNS va permettre de traduire les noms de domaine en adresses IP, nécessaire pour communique. Le serveur DHCP, lui, permet l'attribution de ces adresses IP aux utilisateurs du réseau.

Liaison windows serveur - GLPI

Télécharger le tuto

GLPI permettant une gestion web des utilisateurs, lier GLPI à un annuaire Active Directory permet une gestion centralisée de ces utilisateurs. C'est une façon de faciliter la mise à jour du réseau pour un être humain via l'interface de GLPI. En tout, GLPI permet une meilleure acccessibilité aux utilisateurs qui ont un identifiant unique pour se connecter à plusieurs système et une sécurité renforcée via la centralisation de la gestion.
