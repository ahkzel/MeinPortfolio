Site web sur warhammer40k

Lien vers le code github

Site encyclopédique léger sur l'univers de warhammer 40k. Ce site présente des factions, personnages et planètes connues de cet univers et propose une boutique fictive. On peut s'y créer un compte utilisateur et des comptes joueur, procéder à des achats dans la boutique et consulter les statistiques de cette dernière (bien évidemment les achats ne sont pas réels).

Le site est construit selon une architecture MVC avec une base de données mysql. Il est codé presque intégralement en php. Les liens de la vue redirigent vers le fichier index.php qui initialise tous les controleurs, et en fonction de l'url contenu dans le lien transmis par la vue, il va rediriger vers les contrôleurs associés. index.php initialise également la session et stocke les variables $_GET et $_POST pour les transmettre aux controleurs.

Le site est structuré avec un controleur par modèle et non un contrôleur par vue, ce qui signifie que certaines vues font appel à plusieurs contrôleurs. Les contrôleurs quand à eux s'occupent de chercher des données dans la base de données via les modèles en fonction des $variables qui leur sont données, les procéder, et les renvoyer à la vue qui les affiche sans aucun calcul ou algorithme.

La base de données est composé d'une table factions, personnages, planètes, utilisateur, minifigs, joueur, et achat. Chacune d'entre elles est gérée par un modèle qui est lui même géré par un controleur. Toutes les classes du site ne sont instanciées qu'une seule fois, la connexion PDO est également fait à partir d'un modèle dédié et son controleur stocke cette variable et la renvoie à l'ensemble des controleurs. Les appels entre controleurs sont minimisés, il sont même inexistants, lorsque plusieurs controleurs doivent être mis en commun, le transit est géré par le contrôleur principal qui stocke les variables retournées par les controleurs pour les mettre en commun et les renvoyer à la bonne vue.

Il n'y a qu'un seul fichier css et javascript pour tout le site, celui-ci est d'ailleurs très peu consommateur en javascript et le css est très généralisé et optimisé, toutes les pages ont plus ou moins le même style graphique et j'ai essayé de maximiser la réutilisation de classes déjà crées en faisant mon architecture front-end.

Bot discord

Lien vers le code github

Un de mes premiers projets, réalisé en terminale codé intégralement en python. Ce bot discord est, comme son nom l'indique, un bot discord, qui peut être ajouté à n'importe quel serveur discord et modifié à tout moment si on a son TOKEN unique.

Pour le coder, j'ai fais appel à l'api de discord et ses extensions, ainsi qu'asyncio et diverses API pour la musique telles que youtube_dl, youtube_dl2, spotify, etc. Malheureusement toutes les bibliothèques faciles d'utilisation en python sont obsolètes aujourd'hui principalement pour des raisons de droits d'auteur donc la partie musicale du bot ne fonctionne pas.

Le bot a des fonctionnalités de modération automatique et manuelle, de chat avec les membres du serveur, de musique (en théorie), de roleplay (on peut se créer un personnage avec des attributs), et d'économie évolutive au cours des utilisations.

Il utilise une base de données composée de trois tables qui récupèrent les id des utilisateurs de discord et des serveurs afin de fonctionner en ligne sur plusieurs serveurs différents. Son code est organisé en POO pour accéder à ces bases de données et exécuter toutes les opérations qui ne sont pas relatives à discord. Pour ce qui est des commandes discord, celles-ci sont toutes implémentées dans le main, de même que sa connexion.

Jeu RP texte

Lien vers le code github

Ce jeu est mon premier projet en programmation. Il est codé intégralement en python sans utiliser d'API. Il ne possède pas d'interface utilisateur et n'est pas dynamique. C'est un script écrit qui est exécuté et des choix sont proposés à l'utilisateur tels les "livres dont vous êtes le héro", on pourra des fois faire des choix mais tout est codé à l'avance.

Le projet est très rudimentaire, il est POO tout de même avec une classe pour les joueurs, une pour les pnj, une pour les armes, une pour les armures, une pour les items, une pour les classes de personnage et une classe par classe spécifique qui hérite de la superclasse Classe.

Les objets des classes communiquent entre eux via des méthodes sans jamais appeler de getter et de setter afin de relier un personnage à son équipement par exemple, ou à sa position dans le monde.

Site web sur le cinéma

Lien vers le code github
Lien vers le site

Site web en html css avec un bout de javascript sur le cinéma globalement. Le site possède une page d'accueil qui fait une brève description du site, accompagnée d'un formulaire de newsletter, ainsi que d'une barre de navigation pour naviguer entre les pages. Il possède une page renseignant différents sites de critiques que l'on peut visiter directement via des liens, et un input dans lequel on peut rentrer le nom d'un film série, etc, qui va lier le résultat de cette barre de recherche aux liens des sites externes pour permettre d'aller directement rechercher sur tous les sites la série que l'on veut. Une page films du moment et une page série du moment sont également disponibles, qui possèdent une description des 5 séries et films les plus populaires du moment avec un lien redirigeant vers la page imdb de ce film/série. Le site a également un bouton de changement de thème pour passer du thème clair au sombre et inversement.

Dans le code il y a un fichier html par page et un fichier css en tout qui gère toutes les pages du site, le site est dynamique en partie mais il ne stocke rien, il n'y a donc pas de base de donnée, pas de principe d'utilisateur, lorsqu'on arrive dessus on peut l'utiliser. Le changement de thème et la barre de recherche sont gérées par le script en javascript.

Etant mon premier site web, les fonctionnalités sont limitées et le css est rudimentaire mais le tout est fonctionnel.
