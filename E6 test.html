Projet pour l'épreuve E6

Présentation

Mon projet pour l'épreuve E6 se découpe en deux applications, une web et une desktop.

- L'application Desktop est une application administrateur de gestion et création de questionnaires. Elle permet de s'authentifier ou de se créer un compte dans cette application, puis d'avoir accès aux questionnaires existants, afin d'en ajouter, d'en modifier ou d'en supprimer. Il est également possible via cette application de sélectionner des questions présentes dans un questionnaire pour les modifier, ou d'ajouter ou supprimer une question à un questionnaire, voir créer une nouvelle question en lui attribuant des réponses.

- L'application Web permet de consulter tous les questionnaires publiés en ligne et d'y répondre et sélectionnant une réponse par question dans un questionnaire. L'application web permet également à un utilisateur connecté de créer un ticket à propos d'une question en cas de problème technique ou de problème de contenu sur une question. Le ticket est enregistré et les tickets relatifs à une question sont ensuite consultables sur ce site.
